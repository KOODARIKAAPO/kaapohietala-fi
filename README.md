# kaapohietala.fi

CV ja portfolio. Staattinen sivu, ei riippuvuuksia.

- Sisältö: `src/data.js`
- Rakennus: `node build.js` (tulos kansiossa `dist`). Vercel ajaa tämän automaattisesti.
- PDF:t ja jakokuva: `node make-assets.js` (vaatii Playwrightin), aja kun CV muuttuu.
